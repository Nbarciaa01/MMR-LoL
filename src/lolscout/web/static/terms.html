Términos de uso

Objeto

MMRQ Challenge es una aplicación del grupo para MMR, un grupo cerrado de amigos, que reúne las estadísticas de League of Legends de sus cuentas configuradas. No ofrece registro ni perfiles para el público general y se proporciona sin garantías de disponibilidad permanente.

Uso permitido

El usuario se compromete a utilizar el servicio de forma legítima, sin automatizar peticiones abusivas, intentar acceder a funciones administrativas ni interferir con el funcionamiento de la aplicación o de sus proveedores.

Exactitud y disponibilidad

Las estadísticas pueden retrasarse, variar entre fuentes o dejar de estar disponibles temporalmente. Los rangos y LP proceden de los datos disponibles mediante Riot Games API.

Propiedad intelectual

League of Legends, Riot Games y sus recursos pertenecen a sus respectivos titulares. MMRQ Challenge conserva únicamente los derechos sobre su código y presentación propios.

Limitación de responsabilidad

El servicio se proporciona tal cual. No debe utilizarse para decisiones económicas, competiciones con premios ni actividades que requieran datos oficiales o disponibilidad garantizada.

Cambios

Estos términos pueden actualizarse para reflejar cambios técnicos, legales o de las políticas de Riot Games. La fecha de actualización se mostrará en esta página.
