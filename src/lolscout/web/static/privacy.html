Política de privacidad

Última actualización: 13 de septiembre de 2026

Datos que trata la aplicación

MMRQ Challenge es una aplicación privada para MMR, un grupo de amigos. Consulta los Riot IDs configurados, región, nivel, icono de perfil, clasificación, historial de partidas y estado de partida mediante la API de Riot Games. La aplicación no solicita contraseñas de Riot ni acceso a la cuenta del jugador.

Finalidad

Los datos se utilizan para mostrar el ranking del grupo, calcular el cambio diario de LP, detectar partidas activas y presentar estadísticas relacionadas con League of Legends.

Conservación

Se pueden guardar Riot IDs configurados y snapshots de clasificación necesarios para calcular cambios de LP. Los datos técnicos de caché se renuevan automáticamente y no se venden ni se utilizan para publicidad.

Proveedores

La aplicación utiliza Riot Games API y puede consultar fuentes públicas como Lolalytics para información de builds. El proveedor de alojamiento puede procesar registros técnicos básicos para operar y proteger el servicio.

Solicitudes

Los jugadores pueden solicitar la retirada de su Riot ID del grupo contactando con el responsable identificado en la ficha pública del producto en Riot Developer Portal.
